# AgentGate configuration — copy to .env and adjust.
#
#   cp env.example.txt .env
#
# The broker loads .env at startup (real environment variables win over the
# file, so a container's -e flags override it). `agentgate doctor` reports
# which file was loaded, or that none was found.
#
# All values are optional in development; the ones marked REQUIRED are
# enforced at startup when NODE_ENV=production. Booleans accept
# 1/true/yes/on or 0/false/no/off — anything else is rejected at startup
# rather than guessed.

# --- Broker service ---
AGENTGATE_BROKER_PORT=4790
# Loopback by default. Only change this if TLS is terminated in front of the
# broker; AGENTGATE_ALLOW_PUBLIC_BIND must then confirm a 0.0.0.0 bind.
AGENTGATE_BROKER_HOST=127.0.0.1
# Explicit confirmation that a non-loopback bind is intended. Production
# refuses to start with host=0.0.0.0 unless this is true.
# AGENTGATE_ALLOW_PUBLIC_BIND=false

# development | production. Production enforces the checks above, and refuses
# to generate keypairs server-side (see "Enrolling in production" in README).
# NODE_ENV=development

# --- Storage ---
# Where registry, audit, and session state live. Back this up: it holds the
# organisation's root signing key. A typo here creates a *new* empty registry
# with a new root key, which invalidates every existing agent card — the
# broker warns at startup when it generates one.
AGENTGATE_DATA_DIR=./data

# --- Security ---
# REQUIRED in production. Minimum 32 characters. Guards the /audit and /admin
# endpoints; unset disables them entirely (and with them the dashboard).
# Generate with: openssl rand -hex 32
AGENTGATE_ADMIN_TOKEN=

# How long an issued token is valid. Keep this short — it bounds the damage
# from a leaked credential. Production rejects anything over 1 hour.
AGENTGATE_TOKEN_TTL_MS=900000

# How long an Agent Identity Card is valid before reissue (default 30 days).
AGENTGATE_AGENT_CARD_TTL_MS=2592000000

# Replay window: maximum age of an accepted request, and how long a nonce is
# remembered. Lower is stricter but less tolerant of client clock skew.
AGENTGATE_NONCE_WINDOW_MS=300000

# Maximum accepted HTTP request body.
AGENTGATE_MAX_BODY_BYTES=65536

# --- Admin dashboard ---
# Defaults to on whenever AGENTGATE_ADMIN_TOKEN is set (the dashboard has
# nothing useful to show without one). Set explicitly to override either way.
# AGENTGATE_UI_ENABLED=true
# Where the built dashboard lives, if you serve it from somewhere other than
# src/ui/dist. Build it with: cd ui && npm ci && npm run build
# AGENTGATE_UI_ASSET_ROOT=

# --- Logging ---
# debug | info | warn | error
AGENTGATE_LOG_LEVEL=info

# --- GitHub App (the credential `git push` actually uses) ---
# Unset, the broker issues AgentGate session tokens only — verifiable by
# AgentGate components and meaningless to GitHub. Set, it exchanges each
# authorization decision for an installation token scoped to one repository.
# In production these are all-or-nothing: setting any one requires all of
# them, because a half-configured exchange fails at the first push.
# Requires: npm install --no-save @octokit/auth-app
# AGENTGATE_GITHUB_APP_ID=
# AGENTGATE_GITHUB_INSTALLATION_ID=

# The account the installation belongs to. This is a security control, not a
# convenience: bare repository names resolve against the installation's
# account, so without it a request for "attacker/api" would mint a token
# scoped to "your-org/api".
# AGENTGATE_GITHUB_OWNER=

# Prefer the path form. Environment variables reach process listings and
# crash dumps far more readily than a 0600 file; production refuses to start
# if this file is readable by group or others.
# AGENTGATE_GITHUB_PRIVATE_KEY_PATH=./github-app-key.pem
# AGENTGATE_GITHUB_PRIVATE_KEY=

# GitHub Enterprise Server API root. Unset means github.com. The credential
# helper also treats this host as a forge, so a missing exchange reports the
# unset configuration instead of letting GitHub reject the push.
# AGENTGATE_GITHUB_API_BASE_URL=

# Upper bound on the token exchange, so a stalled GitHub API becomes a prompt
# denial rather than a `git push` that hangs.
# AGENTGATE_GITHUB_MINT_TIMEOUT_MS=8000

# Repository this credential is for, as "owner/name". Only needed where
# `git config credential.useHttpPath true` is not in effect — CI, or an agent
# process with no global git config. Set this on the *client*: on the broker
# it becomes a silent global default for every request that omits one.
# AGENTGATE_REPOSITORY=
